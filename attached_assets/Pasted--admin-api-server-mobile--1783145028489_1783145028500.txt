এখন পর্যন্ত পুরো কোডবেস (admin + api-server + mobile) খুঁজে যা যা সমস্যা পেয়েছি, সব একসাথে দিলাম — গুরুত্ব অনুযায়ী সাজানো।

## 🔴 ১. Admin-এর "Master Enable" টগল আসলে কাজই করে না

**সমস্যা:** Admin → Advertisements পেজে "Master Enable" টগল সেভ হয় `PUT /v1/ads/global-config` দিয়ে, যা `globalConfig` (JSON) কলামে `isEnabled` লিখে।

কিন্তু mobile app-এর `global-ad-engine.ts`-এ:
```js
const adsEnabled = json?.data?.adsEnabled ?? ...;  // এটা আসে settings.isEnabled থেকে — ভিন্ন DB কলাম!
if (typeof adsEnabled === 'boolean') {
  base.isEnabled = adsEnabled;  // ← globalConfig.isEnabled কে ওভাররাইট করে দেয়!
}
```
`AdSetting.isEnabled` হলো `AdSetting` টেবিলের একটা **আলাদা কলাম**, যা `PUT /v1/advertisements/settings` endpoint দিয়ে আপডেট হয় (ডিফল্ট `true`)। Admin UI-তে এই endpoint কল করার কোনো বাটন/ফর্মই নেই। ফলে —
- Admin "Master Enable" অফ করলেও mobile-এ ads বন্ধ হয় না (কারণ `adsEnabled` DB কলাম সবসময় `true` থেকে যায়)।

**সমাধান (backend):** `updateGlobalAdConfig()`-এ config সেভের সময় `AdSetting.isEnabled`-কেও sync করে দিন —
```ts
async updateGlobalAdConfig(config: Record<string, unknown>) {
  const isEnabled = typeof config.isEnabled === 'boolean' ? config.isEnabled : undefined;
  const settings = await this.prisma.adSetting.upsert({
    where:  { key: AD_SETTING_KEY },
    update: { globalConfig: config as Prisma.InputJsonValue, ...(isEnabled !== undefined && { isEnabled }) },
    create: { key: AD_SETTING_KEY, globalConfig: config as Prisma.InputJsonValue, isEnabled: isEnabled ?? true },
  });
  return { success: true, globalConfig: settings.globalConfig };
}
```

## 🔴 ২. Smartlink/VAST-এর persistent counter কখনো রিসেট হয় না

**ফাইল:** `mobile/lib/global-ad-engine.ts`

`ad_engine_switch_count` AsyncStorage-এ জমা থাকে, app uninstall না করলে কখনো রিসেট হয় না। আগে (Frequency অফ থাকা অবস্থায়) যতবার চ্যানেল পাল্টানো হয়েছে সেটাও কাউন্ট হয়ে গেছে — তাই এখন Frequency=3 সেট করলেও `pos === slFreq` কখন মিলবে সেটা predictable না, টেস্ট করলে "কখনো আসে না" মনে হয়।

**সমাধান:** টেস্টিং-এর সময় counter রিসেট করার একটা ডেভ-মোড অপশন রাখুন —
```ts
export async function resetSwitchCounter() {
  await AsyncStorage.multiRemove([KEY_SWITCH_COUNT, KEY_LAST_SMARTLINK]);
}
```
এবং Admin-এর config সেভ করার সময় (frequency/cooldown পাল্টালে) `invalidateGlobalAdConfig()` + কাউন্টার রিসেট — দুটোই করা ভালো, নাহলে অ্যাডমিন সেটিং পাল্টালেও পুরনো cycle position থেকেই হিসাব হবে।

## 🟠 ৪. `ChannelAdGateProvider`-এ config fetch একবারই হয়, retry নেই

// channel-ad-gate-context.tsx

export function ChannelAdGateProvider({ children }) {

## 🟡 ৭. "My Teams" ডেটা-শেপ মিসম্যাচ (ক্র্যাশ না, কিন্তু ভুল ডেটা)

**ফাইল:** `mobile/app/sports.tsx` + `api-server/.../sports.service.ts`

`GET /v1/sports/my-teams` রিটার্ন করে:
```json
[{ "id": "...", "userId": "...", "teamId": "...", "team": { "name": "...", "abbr": "..." } }]
```
কিন্তু mobile পড়ে `t.name`, `t.abbr` সরাসরি — যা `undefined`, তাই সবসময় ফলব্যাক "TM" দেখায়।

**সমাধান (`sports.tsx`):**
```ts
const myTeams = useMemo(() => {
  const items = Array.isArray(myTeamsData) ? myTeamsData : [];
  const mapped = items.map((t: any) => {
    const team = t.team ?? t; // wrapper হলে .team, না হলে সরাসরি
    return {
      id: team.id,
      abbr: team.abbr || team.name?.slice(0, 3).toUpperCase() || 'TM',
      name: team.name || '',
      gradient: teamGradients[team.abbr] || ['#7C3AED', '#2563EB'],
    };
  });
  return [...mapped, null];
}, [myTeamsData]);
```
