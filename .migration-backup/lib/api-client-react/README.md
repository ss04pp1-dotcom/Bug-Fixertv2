# @workspace/api-client-react

React Query bindings generated by [orval](https://orval.dev/) from
`lib/api-spec/openapi.yaml`.

## Regenerating after `openapi.yaml` changes

```bash
pnpm --filter @workspace/api-spec run codegen
# or directly:
npx orval --config lib/api-spec/orval.config.ts
```

The files under `src/generated/` are overwritten on every run. Do not edit
them by hand. If you see only `healthCheck` exported from
`src/generated/api.ts`, the generated output is **stale** — re-run codegen
after installing `orval` (`pnpm install`).
